## Model clarification requested by the user

Actor: camera CNN/spatial-softmax features concatenated with normalized proprioception
→GRU128→MLP(128,128)→Gaussian action means. Thus GRU is before the action MLP.
An optional encoder MLP before GRU is a valid future architecture ablation; no such
change was made. Keep architecture fixed during the current LR/entropy comparison.
Critic is a separate GRU128→MLP(128,128)→value using privileged observations. Actor
excludes privileged object/goal/variant state. Actor memory=none removes its GRU but
keeps the critic recurrent. Actual policy module/config remains the source of truth.
