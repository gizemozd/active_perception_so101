## Model clarification requested by the user

Actor: camera CNN/spatial-softmax features concatenated with normalized proprioception
→GRU128→MLP(128,128)→Gaussian action means. Thus GRU is before the action MLP.
An optional encoder MLP before GRU is a valid future architecture ablation; no such
change was made. Keep architecture fixed during the current LR/entropy comparison.
Critic is a separate GRU128→MLP(128,128)→value using privileged observations. Actor
excludes privileged object/goal/variant state. Actor memory=none removes its GRU but
keeps the critic recurrent. Actual policy module/config remains the source of truth.

## Model, sensing and task details discussed with the user

| Condition | Actor images | Plug action dimensions | Camera behavior |
|---|---|---:|---|
| wrist | wrist RGB | 3 | No learned external-camera control |
| wrist_static | wrist + fixed external RGB | 3 | External viewpoint7 is fixed |
| initial | wrist + external RGB | 8 | Camera targets can change only during first1s |
| active | wrist + external RGB | 8 | Camera targets can change throughout episode |

`wrist_static` means two simultaneous image streams, not a stationary wrist camera.
View7 is a promising diagnostic candidate, **not an optimized fixed-camera baseline**.
Initial-only freezes camera targets after inspection; images continue to refresh.
It is different from freezing/staling images, which is a separate evaluation ablation.
All four share the first one-second manipulation pause; episode duration3.5s,
control25Hz, physics timestep0.002s with20 substeps, clean occlusion and balanced
hidden-prong variants. Success requires distance below2mm for three control steps.

Actor image input is RGB128×96 (tensor3×96×128), uint8 until divided by255 in the CNN.
Each view has a separate CNN: Conv3→16 (kernel5,stride2,pad2), ELU, Conv16→32
(kernel3,stride2,pad1), ELU, spatial softmax giving64 features per view. The51 scalar
inputs are12 joint positions,12 scaled velocities,12 joint targets,3 TCP targets,
5 camera targets,6 fixed-calibration values and normalized episode time. Thus the
GRU receives115 features with one image or179 with two. It has one128-unit layer,
followed by128/128 ELU MLP and Gaussian action means, with learned per-action std
initialized0.4. No frame stacking. `memory=none` feeds the same fused features directly
to the actor MLP; it does not remove the critic GRU.

Critic input has76 scalars: those51 plus privileged TCP/object/tip/goal positions,
object quaternion/linear/angular velocity and occlusion parameters. It uses a separate
GRU128 and128/128 MLP to produce a scalar value. Privileged inputs are excluded from
the actor. Images and variant labels are not privileged critic inputs in this design.

Three manipulation actions are normalized absolute Cartesian TCP targets, mapped to
workspace bounds with IK; orientation and gripping are fixed. Environment clips actions
to[-1,1], caps TCP target change at0.03m/control step, and pauses manipulation for1s.
The five additional actions change camera xyz/pan/tilt targets with maximum increments
0.01m/0.05rad and workspace bounds. Policy outputs are Gaussian before clipping;
diagnostic action saturation measures the fraction outside the effective action limits.

Shared original PPO:24 rollout steps,4 epochs,8 minibatches, Adam, initial LR3e-4,
adaptive KL target0.01, entropy0.003, gamma0.99, GAE0.95, clip0.2, gradient norm1.
Reward is3×potential progress +10×success −0.005 time cost − action cost; see current
`mdp.py` for exact potential/action normalization. No reward change was made for tuning.
For the full restored geometry rationale read [PLUG_RESTORATION](PLUG_RESTORATION.md)
and [STUDY](STUDY.md), not the obsolete centered-pin task configuration.
