What changed

  • Incremental control: each XYZ action requests at most5 mm per axis per40 ms step. A zero command holds the previous target. Workspace limits and the1-second inspection pause remain.
  • Exploration: initial normalized standard deviation0.25 gives1.25 mm XYZ request noise per axis. Entropy coefficient0.001, adaptive initial learning rate0.0003. Standard deviation is learned; the initial value is not a permanent cap.
  • Stage reward: physical TCP lift above87 mm, then XY alignment within3 mm while TCP remains above84 mm, then insertion. Stage density lies in[0,3]; reward is0.2×density +100×held-success −0.005 −0.001×mean squared manipulator action. Current XY/Z error still determines precision credit after alignment.
  • Inputs: actors receive their specified RGB views and measurable robot state. True object/goal positions and reward-stage history are available only to reward/critic. All actors use a compact GRU.

All three policies use the same three XYZ controls. Physical success is the unchanged body distance<2 mm for three consecutive samples, within the original3.5-second horizon. No yaw action or extra orientation criterion is enabled in this comparison.
