Transfer: repair the transport learning signal

This state-only diagnostic follows the 20M transfer run that lifted the cube on about 99.5% of held-out episodes but never transported, placed or released it. That run used a unit-amplitude distance reward, which yielded little incentive to move a lifted cube away from the source.

The new opt-in transfer_transport reward raises the lifted transport term to 2 + 6 exp(-distance / 0.06). This isolates the observed failure stage; physical success criteria, action bounds, task geometry, and ±20 mm reset jitter remain unchanged. No RGB run should use this revision unless privileged evaluation shows transport learning.
