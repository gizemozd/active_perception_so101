Protocol and task changes

Each fresh policy uses compact CNN + GRU PPO, 24 steps/update, 2048 parallel environments, initial Gaussian std 1.0, adaptive learning rate 0.0003, entropy 0.01, four epochs and eight minibatches. Training uses dynamic optical occlusion, 96×72 RGB, a 12-second horizon, and independently randomized object/goal XY within ±20 mm. All conditions share manipulation controls, reward, task distribution, recurrent memory, and total transition budget.

Transfer commands XYZ plus gripper; push commands XYZ with a rigid pushing tip. Camera-arm actions remain five joint increments. Dense stage rewards encourage approach, pickup, transport and release; success adds 100. Transfer requires bilateral grasp/lift history, floor support, release, settling and withdrawal for five samples. Push requires the actual tip to withdraw more than 25 mm, no load-bearing manipulator contact, goal tolerances and low speed for three samples. Scoring reads current integrated qpos.

The seed-zero wrist+static policy for each task trains first. At least 80% success on both clean and dynamic 512-episode validation sets was intended to enable expansion; that automatic expansion is now disabled. This was the earlier launch protocol; it is now suspended. This gate is a competence check; it is not evidence of a sensing advantage. Validation reset seeds start at 30000; final 1024-episode test sets start at 80000.

Static transfer view 4 was chosen from the earlier segmentation screen; push uses home view 0. These are specified baselines, not learned-success-selected best-static cameras. Static viewpoint search, initial-inspection and prescribed-scan alternatives remain limitations of a broad claim that continuous active motion is necessary.

Slurm time-limit signals save a checkpoint and schedule a continuation with the same model, optimizer and W&B identity. Simulator/RNG/episode/GRU state resets on resume. Each continuation is logged; total budgets count environment transitions, not simulator substeps or vector steps.
